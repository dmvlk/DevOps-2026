# SVN vs Git

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это просто указатель на коммит. Создание ветки мгновенно и не требует копирования файлов.
В SVN ветка — это копирование директории на сервере. Это медленно и занимает много места.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN — централизованная система. Коммит отправляется на центральный сервер, поэтому нужен интернет.
В Git коммит создаётся локально — интернет нужен только для push/pull.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

В legacy-проектах, где уже есть инфраструктура SVN, обученные сотрудники и нет смысла мигрировать.
