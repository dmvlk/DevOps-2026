# Git в VS Code vs Git в Терминале

## Что удобно в VS Code

1. **Встроенная панель Source Control** — все изменённые файлы видны сразу, можно кликнуть и посмотреть diff, не вводя `git diff` вручную.

2. **Визуальный редактор merge-конфликтов** — при конфликте VS Code подсвечивает варианты («Accept Current», «Accept Incoming», «Accept Both») и позволяет разрешить конфликт в пару кликов.

3. **История и граф коммитов** — через расширение GitLens или встроенный Git Graph можно наглядно видеть ветвление, кто и когда сделал коммит, без `git log --graph`.

## Что удобнее в терминале

1. **Interactive rebase (`git rebase -i`)** — в VS Code это скрыто за UI, а в терминале полный контроль: `pick`, `squash`, `fixup`, `drop`, `reword`. Особенно удобно, когда нужно переписать историю нескольких коммитов сразу.
